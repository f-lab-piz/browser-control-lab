## Confirmed findings

1. **P2 — Do not prune a matching shadow host using an unassigned light child.** `extension/page-agent.mjs:44` (with `parentOf` at line11 and `all` at line7). If a host has an open shadow root containing text `Prune Needle` and an unassigned light-DOM span with the same text, `getByText('Prune Needle',{exact:true}).evaluateAll(...)` returns only the unrendered light span (`rects:0`); the visible host (`rects:1`) is removed. The span is not a composed descendant of the host, so the composed-descendant pruning condition in REQ-SCOPE-GETBYTEXT-001 is false and the host must remain. `getByText(...).click()` consequently fails with ACTIONABILITY_TIMEOUT instead of finding the displayed target. Active slots also expose inactive fallback children as candidates. `all()` includes light and fallback children even when the shadow/slot replaces them, and `parentOf()` then treats every DOM parent as a composed parent. The main pruning failure is a confirmed contract violation; no blanket claim is made that all disconnected-from-flat-tree DOM must be excluded under the CSS-hidden policy. **Pre-existing**, reproduced with exactly base0452cbe api-source/page-agent while fixing all other sources and the probe. Independent artifacts: `output/pr20-review/independent-probes.json` and `output/pr20-review/baseline-probe.log`; runnable fixture/script `output/pr20-review/probe.mjs`.

2. **P2 — Evaluate CSS over the Scope document, including its document element.** `extension/page-agent.mjs:41` uses `all()` whose default root at line7 is `document.body`. On an ordinary HTML document, product `locator('html').count()` and `locator('head').count()` return0 while the independent native read returns1 each. `locator('html').getAttribute(...)`/waits consequently report absence even though the element belongs to this selected document. REQ-SCOPE-LOCATOR-001/C01 promises current-Scope-document CSS candidates and specifies no body-only restriction. **Pre-existing**, identical in the base-owned-source control run. Same probe artifacts contain the independent native oracle.
