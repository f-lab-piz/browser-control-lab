# B01B: 세션 선언 상태와 실행 의미

0.2.0은 top-level 선언을 전역 속성 대입으로 바꾸지 않는다. 확장 세션별 QuickJS의 global async/strict 실행으로 var/let/const와 lexical 환경을 유지한다. top-level await, 기존 브라우저 핸들, 명시 출력은 같은 확장→브라우저 경로를 사용한다. 중계기의 평가기나 계정 서비스를 추가하지 않았다. Sol6.1 high [독립 리뷰](../reviews/pr12-b01b.md) PASS 후 PR#12가0446e5b로 머지됐다. 비차단 P3 현황 문구는 B01C에서 정리한다.

## 구현 근거와 이행

범용 엔진의 공개 [QuickJS header](https://github.com/bellard/quickjs/blob/master/quickjs.h)는 global 코드에 ASYNC(1<<7)로 top-level await/Promise 반환을, STRICT(1<<3)로 strict 실행을 정의한다. 설치된 범용 WASM0.32.0에서 실제 확장 제품 테스트로 확인했다. 경쟁 제품의 원본 코드·번들·WASM은 사용하지 않았다.

0.1.x에서 같은 이름의 const를 재선언하던 예제는 let 초기 선언과 이후 대입으로 이행한다. package/확장 version을0.2.0으로 맞췄으며 [사용 안내](../runtime-usage.md)에 재선언/대입 차이를 명시했다. 기존 재선언 허용 회귀를 단순 삭제하지 않고 전용 충돌·무부작용 검증으로 대체했다. AST는 모듈 import/export를 거절하고 선언 소스를 다시 쓰지 않는다.
