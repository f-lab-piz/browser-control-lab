# B02A: 공통 검색과 접근 이름

접근 이름, 검색 본문, 출력 이름을 분리했다. getByRole/getByLabel은 최종 이름과 명시 라벨을 사용하고, getByText/filter는 실제 composed 본문 전체를 검색한다. 명시 IDREF의 범위·우선순위와 순환을 처리하고 잘못된 검색 옵션은 hostcall 전에 거절한다. 개인용 로컬 중계기와 외부3/내부64 API를 유지한다. 독립 리뷰 전이며 slice는 in-progress다.

## 회귀 해석과 남은 범위

기존 details fixture의 summary도 이제 shadow 본문에서 Shadow summary 이름을 얻어 summary와 내부 button 둘이 매칭된다. 실제 tag identity SUMMARY/BUTTON을 확인하고 native button CSS+filter로 대상을 명시했다. strict를 약화하거나 첫번째를 고르지 않았으며 hidden content 제외·실제 내부 버튼 click 결과 clicked 조건을 유지한다. 초기 실패 로그도 보존한다.

13부모/21조건의 국소 검증이며 전체185REQ·모든 AX 규칙/브라우저/회사 사이트의 완료를 주장하지 않는다. B02B query 조합·B03A 전체 프레임 수명주기·B03B snapshot·B04~B06는 계속 남아 있다. PR18의 과거 프레임조회 실패도 최종 감사 전까지 미해결 추적으로 유지한다. 정확head 새 컨텍스트 Sol6.1 high 독립 리뷰와 정상 merge gate가 필요하다.
