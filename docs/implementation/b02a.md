## 독립 리뷰1차 지적과 수용 범위 보완

정확f664dd1의 [Sol6.1 high 독립 리뷰](../reviews/pr20-b02a.md)는 CHANGES_REQUESTED였다. 초기10개 제품/전체127·headed42는 통과했으나 현재 요구에서 빠진 기존 P2 두 건을 독립 fixture와 정확base2파일 대조로 발견했다. 이 단계의3/10→10/10은 과거 검증 범위이며 추가한12개 검증으로 현재 판정을 확장한다.

- REQ-SCOPE-LOCATOR-001-C01 추가: CSS를 documentElement부터 열거하여 html/head/title/meta/style/script/noscript/template의 연결 요소를 조회한다. main/child html의 data-scope와 lang·title·content·inert JSON 원문을 native와 대조한다. template.content의 비연결 후손은 count0이다. HTML/SVG script/style 본문은 검색에서 제외하며 명시 CSS/textContent는 별도다.
- REQ-SCOPE-GETBYTEXT-001-C02 추가: 미할당 light child와 활성 slot의 비활성 fallback은 composed 전역 text 후보에서 제외한다. SLOT 자체가 raw 텍스트의 실제 host를 대신하지 않는다. CSS로는 해당 물리 DOM을 여전히 조회할 수 있다. 일반 CSS hidden 본문과 활성 fallback·배정된 요소는 보존한다. 이는 CSS hidden을 모두 제거하는 우회가 아니다.
- 실제 Prune/Raw Slot/Active Fallback의3개 컨트롤을 getByText로 클릭하면 fixture의 trusted 이벤트 순서/판정이 PASS다. Ghost 때문에 host가 제거되거나 중복 SLOT이 남은 Before는 이 동작을 완수하지 못한다. native oracle도 같은3개 UI 입력/판정을 독립 검증한다.

추가 fixture는 selection-boundaries로 분리하여 원래 selection 비교 DOM을 바꾸지 않았다. 처음에는 native button에 attachShadow를 시도해 초기화가 중단됐고 native oracle이 이를 잡았다. 허용되는 div 호스트로 바로잡고 native/제품/최종 Before를 다시 실행했다. 해당 초기 실패는 harness 이력이며 제품 개선 점수로 쓰지 않는다.
