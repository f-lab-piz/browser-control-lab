# PR #12 B01B 독립 리뷰

## 발견 사항

### P3 — 최신 구현 현황에 B01B가 미착수와 진행 상태로 동시에 남는다

- 위치: `implementation/index.md:5` (같은 파일 `:8`의 신규 B01B 항목과 충돌).
- 재현: 지정 head의 현황 문서를 읽으면 5행은 `B01B~B06C:미착수`라고 하고, 8행은 B01B의 이슈·국소 제품 PASS·독립 리뷰 대기 상태를 적는다. `planning/implementation-plan.json`의 B01B는 in-progress다.
- 기대/실제: 최신 현황의 미착수 범위는 B01C 이후여야 한다. 이전 범위 문장을 남긴 채 이번 PR에서 B01B 진행 항목을 추가해 모순이 생겼다.
- 영향: 문서 독자가 B01B 착수 여부를 오해할 수 있다. 제품 동작·검증 결과·머지 gate를 바꾸는 문제는 아니며 비차단 정리 사항이다.

검토 범위에서 확정된 P0/P1/P2는 없다. 위 P3는 이번 PR의 신규 진행 기록과 기존 문장이 충돌해 발생한 현황 오류다. 기능 실패의 가설을 확정 버그로 올리지 않았다.

환경은 macOS15.6.1 arm64, Node v25.2.1, Python3.14.2, Chrome for Testing145.0.7632.6이다. 모든 제품 실행은 별도 임시 프로필을 사용했고 helper의 close/finally로 자체 브라우저·중계기·fixture를 종료했다. 종료 뒤 해당 테스트 명령/임시 프로필 프로세스가 남지 않은 것도 확인했다.

제품 조작은 HTTP→확장 offscreen→세션별 Worker의 QuickJS→브라우저 경로다. 중계기는 사용자 코드를 평가하지 않는다. 새 global async/strict 플래그와 소스를 유지하는 AST 검증으로 var/let/const의 지속·재선언·대입 의미를 native VM이 결정하는 것을 테스트와 연결 코드에서 확인했다. 충돌 테스트는 실제 클릭 앞에 marker 증가를 두고, 준비 단계에서 탭을 activate한 뒤 요청 오류·업무 서버 클릭0·값0·기존 binding·generation·타세션을 함께 검증한다. 정상 var/let 대입, const 보호, 구문/import/export 사전 오류, host await 전후 구조분해·closure/class 지속, 서로 다른 실제 탭 소유와 명시 텍스트/PNG 출력도 확인했다. 제품 클릭·입력을 Playwright가 대신하거나 fixture PASS를 주입하지 않는다.

새 프레임 oracle은 제품에서 선택한 target id에 별도 CDP 연결로 접속하지만 실제 Page.getFrameTree의 id와 고정 기대 host/selector의 DOM을 독립 판독한다. 제품의 frame 목록·PASS를 그대로 복사하지 않는다. Target.attachToTarget/Page.getFrameTree/읽기 전용 Runtime.evaluate만 쓰고 auto-attach·시작 pause·입력·업무 상태 변경은 없다. 비일시정지 Playwright의 프레임 목록 누락 실패 로그가 보존되어 있고 selector/10초 제품 발견 제한은 유지됐다. 연결된 기존 mail/booking·파일 bytes·경계 회귀도 통과했다.

package/lock/확장 version은0.2.0이고 guide는 현재 package version과 runtime-usage 안내를 읽는다. astring 제거·라이선스/범용 엔진 출처와 기존 const 재선언 예제의 let/대입 이행도 일치한다. Codex/Aside 비교는 DOC/HISTORICAL/미측정을 구분하고 이번 신규 경쟁 실측0·성능 우위 미주장 상태를 유지한다. PR10 보존 리뷰의 정확 head와 로컬 base367a5d2의 실제 GitHub squash merge #10 기록도 대조했다.

Before 결과의 head/dirty 메타데이터는 복사본이 상위 원본 checkout의 Git 정보를 읽으므로 base checkout이라는 증명이 아니다. 제품 두 파일의 base hash와 고정된 나머지 tracked 소스 대조를 근거로 통제 비교라고 판단했다. 저자 증거도 전체 당시 환경 재현과 이 통제 비교를 구분하고 있어 주장의 범위는 일치한다.
