## 순서와 경계
단계1의 임시 bootstrap probe와 제품 런타임을 구분한다. 제품 JS는 확장 내부 WASM 엔진에서 실행한다. Playwright는 브라우저 기동/확장 로드/독립 검증만 담당한다. 제품 대신 입력을 수행하지 않는다. 실제 회사 사이트 검증은 접근 가능한 환경에서 별도 기록한다.

## 2026-11-01 진행 결과

단계1–5의 첫 실행 구현과 복잡 fixture 업무 판정을 완료했다. 단계6은64 API 기본 호출과 제한/오류/파일/입력의 회귀를 구현하고 카탈로그에 증거를 연결했다. 단계7은 실제 네이버 검색 결과 관찰까지 통과했으며 결과 선택·복귀 흐름과 정량 누락률 평가는 남았다. 단계8의 로컬 재현·개발 문서와 소스 패키지를 준비했다.

다음 반복은 status.md의 남은 범위를 순서대로 처리한다. 먼저 추가 실패 fixture와 연결 복구, 다음으로 미지원 옵션과 HTML DnD, 그 뒤 브라우저 어댑터·상용 배포 조건을 검증한다. 현재 버전을 완전한 상용 제품으로 표시하지 않는다.
