# page.waitForLoadState

## 계약과 적용 범위

대상: 확장 QuickJS에 공개하는 기존 API.

공통 계약: [runtime](../common/runtime.md), [dom-frames](../common/dom-frames.md). Page/Frame의 Scope 메서드는 같은 API로 센다. 공통 필수 조건도 이 API의 개발 수용 기준에 포함한다.

- 목적: interactive/domcontentloaded는readyState가loading이아닌상태,load는complete로정의한다.
- 입력/기본값: state:interactive/domcontentloaded/load(기본interactive),options.timeout?:positive ms(기본10000).
- 출력/성공 의미: Promise<string> document.readyState.
- 허용 부작용: 관찰만.
- 오류/경계: networkidle은지원하지않아즉시거절하며SPA업무완료와load를동일시하지않는다.
- 재시도: 읽기는 최신 문서 상태로 다시 관찰할 수 있다. 입력은 완료 여부를 먼저 확인하며 응답 유실만으로 재전송하지 않는다.
- 지원: Chrome debugger/CDP, 허용된 HTTP(S), 현재 연결 DOM. Firefox/Safari·closed Shadow·모든 사이트 완전 지원은 이번 약속이 아니다.

- 근거: USR, CODE, DESIGN. 문서/이력에서 도출한 목표 계약이며 현재 충족의 증명은 아니다.

- 상세화 판단: `DETAIL-page.waitForLoadState` — 구현 전 설계 수용, 실제 충족 미검증. 공통 조건은 중복 정의하지 않고 이 API에 필요한 관찰 가능한 경계를 구체화한다.
