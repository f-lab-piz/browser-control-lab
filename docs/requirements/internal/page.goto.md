# page.goto

## 계약과 적용 범위

대상: 확장 QuickJS에 공개하는 기존 API.

공통 계약: [runtime](../common/runtime.md). Page/Frame의 Scope 메서드는 같은 API로 센다. 공통 필수 조건도 이 API의 개발 수용 기준에 포함한다.

- 목적: 새 문서에 연결 가능한 상태까지 기다리고 탐색 실패를 구분한다.
- 입력/기본값: url:절대 HTTP(S) URL.
- 출력/성공 의미: Promise<boolean>; 지정 탐색 준비 성공true.
- 허용 부작용: 해당 탭 탐색·문서 ref 갱신.
- 오류/경계: 잘못된 URL·네트워크 실패에서 이전 DOM 관찰을 새 문서 성공으로 반환하지 않는다.
- 재시도: 읽기는 최신 문서 상태로 다시 관찰할 수 있다. 입력은 완료 여부를 먼저 확인하며 응답 유실만으로 재전송하지 않는다.
- 지원: Chrome debugger/CDP, 허용된 HTTP(S), 현재 연결 DOM. Firefox/Safari·closed Shadow·모든 사이트 완전 지원은 이번 약속이 아니다.

## 개별 요구사항

### REQ-PAGE-GOTO-001

- 참고 방식: [Codex·Aside의 공개 방법과 우리 판단](../reference-methods/lifecycle-evaluation.md#ref-page-goto). 관련 근거가 조건 전체의 충족을 의미하지 않는다.
- 수준/판단: **MUST / 수용** (초안 설계 결정, 2026-11-01).
- 규범: 새 문서에 연결 가능한 상태까지 기다리고 탐색 실패를 구분한다.
- 근거: USR, CODE, DESIGN. 문서/이력에서 도출한 목표 계약이며 현재 충족의 증명은 아니다.
- 충족 상태: **미검증**. 기존 구현 사실과 기본 PASS는 아래 후보 경로에서만 참고한다.
- Given: 아래 REQ-PAGE-GOTO-001-C01부터 C02까지의 독립 준비 조건을 사용한다. 각 반례는 별도 run이다.
- When: 조건별 실행 절차를 실제 브라우저 경로로 수행하고 독립 관찰/이벤트/파일 바이트로 판독한다. 이번 문서 작업에서는 실행하지 않았다.
- Then: 아래 각 조건의 판정식을 모두 만족해야 이 요구의 적용 범위를 충족한다. 하나의 정상 호출로 다른 조건의 통과를 대신하지 않는다.
- 검증 계획: `PLAN-PAGE-GOTO-001`; [매핑](../verification-matrix.json). 정상과 적용되는 거절·무부작용/부분효과를 실제 확장 경로로 확인한다.


- 상세화 판단: `DETAIL-page.goto` — 구현 전 설계 수용, 실제 충족 미검증. 공통 조건은 중복 정의하지 않고 이 API에 필요한 관찰 가능한 경계를 구체화한다.

#### REQ-PAGE-GOTO-001-C01

- 조건: 탐색 준비는 목적 문서의 readyState가 interactive 이상이고 새 document identity에 연결된 상태다.
- 준비: A 문서와 지연 로딩 B
- 실행: goto(B) 후 즉시 snapshot
- 판정: B의 URL/document에 연결되며 A 내용을 B로 반환하지 않는다.
- 근거/상태: DESIGN · 수용된 목표 상세조건 · 제품 미검증.

#### REQ-PAGE-GOTO-001-C02

- 조건: redirect는 최종 URL/문서를 관찰할 수 있어야 한다.
- 준비: B가 C로 HTTPredirect
- 실행: goto(B) 후 URL 조회
- 판정: 최종 C를 확인하고 원래 B와 최종 C를 혼동하지 않는다.
- 근거/상태: DESIGN · 수용된 목표 상세조건 · 제품 미검증.

- 준비: 느린 B와 동일 Page C 탐색 경합
- 실행: goto(B) 대기 중 C/timeout
- 판정: B 성공으로 오인하지 않고 현재 문서/취소·불확실을 관찰한다.
- 근거/상태: DESIGN · 수용된 목표 상세조건 · 제품 미검증.

## 현재 사실과 근거 한계

기준 구현은 `700a6a06af3f97729327afaf9becb4ee29bb475b`. [카탈로그](../../api-catalog.json)의 과거 상태 `verified-basic`는 기본 호출/당시 제한 기록이다. 본 명세의 모든 옵션·반례 충족을 뜻하지 않는다.
