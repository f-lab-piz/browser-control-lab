# 도구 요구사항 v1 · 개발 전 명세

2026-11-01. 제품 기준 `700a6a06af3f97729327afaf9becb4ee29bb475b`.

이 문서는 **목표 계약**이다. 기존 코드·카탈로그의 기본 PASS와 이 계약의 충족을 구분한다. 현재 모든 요구의 새 검증 결과는 미검증이며, 실제 구현/테스트의 차이는 개발 backlog로 넘긴다. 제품 구현은 이번 작업에 포함하지 않는다.

읽는 순서: [범위/불일치](inventory.md) → [색인](index.json)의 개별 명세 → [공통 계약](common/selection.md) → [근거](sources.md) → [검증 매핑](verification-matrix.json) → [복합 검증 설계](test-design.md) → [개발 backlog](backlog.md). 외부 3개·내부 64개 명세가 있으며 공통 5개 문서는 API 수에 더하지 않는다.

## 명세와 상태 해석

- MUST: 다음 개발 버전 수용에 필수. 현재 구현과 달라도 규범을 낮추지 않는다.
- SHOULD: 이유를 남기고 후순위로 할 수 있는 품질 조건.
- 후속 후보: 현재 수용 범위 밖. 채택 전 구현하지 않는다.
- 수용/기각/보류는 요구 판단이다. 충족/부분 충족/미구현/미검증은 구현·증거 상태다.
- 이번 v1에서 `미검증`은 새 규범 전체의 확장 경로 판정을 실행하지 않았다는 뜻이다. 기존 테스트가 없다는 단정도, 현재 코드가 모두 실패한다는 뜻도 아니다.
- Markdown의 `REQ-*` 단락이 규범 원본이다. index는 경로/의존 공통 계약, matrix는 검증계획/상태/후보 테스트만 담는다. matrix의 Given/When/Then은 판정 설계이며 규범을 변경하지 않는다.
- 정상·거절·무부작용은 적용되는 경우 모두 검증한다. 포커스/스크롤/웹 핸들러가 이미 실행된 이후의 실패는 원자적 rollback으로 꾸미지 않고 관찰된 부분 효과를 기록한다.
- 오류 문구는 의미 분류(입력/미지원/없음/다중/stale/권한/timeout/직렬화/부분효과)를 요구한다. 코드명의 대소문자까지 기존 제품과 호환을 약속한 것은 아니다. 개발 시 guide와 안정적인 코드 대응표를 함께 확정한다.

## 환경과 재현 등급

제품 대상은 Chrome 계열의 확장 debugger/CDP 어댑터와 허용된 HTTP(S) 페이지다. 모든 브라우저·사이트, closed Shadow/캔버스/PDF 의미 추출, 임의 Pod 목적지 저장, MCP 배포 구현은 현재 범위 밖이다. 보안·권한·프레임 제한은 명시 실패로 처리한다.

검증 등급은 계약/unit, fixture 자체 Playwright oracle, 실제 HTTP→확장→QuickJS→브라우저 E2E, 외부 사이트 관찰로 나눈다. 기존 테스트 후보 연결은 새 요구의 PASS가 아니다. 회사 페이지·외부 사이트 실환경은 접근 전까지 미검증이다. snapshot 완전성은 현재 DOM 수집 범위와 모델에 돌려준 출력 범위를 나누어 판정한다.

## 독립 검토 절차

새 컨텍스트의 Sol 6.1 high가 세 번 순차 검토한다. 기본 계약 → Codex/Aside 비교·조합 → 반례·검증 가능성이다. 각 회차의 원문 보고서와 모든 제안의 수용/기각/보류 이유를 reviews에 남긴 뒤 다음 회차를 진행한다. 비교가 필요하다는 이유로 경쟁 도구의 미측정 수치나 옵션 지원을 만들어내지 않는다. 코드/테스트 실행과 문서 검증을 구분한다.

수용된 요구마다 구체적 검증계획이 연결되고 필수 충돌을 정리하면 개발 전 단계 완료다. 이는 제품 개발·배포 완료나 PR 승인을 뜻하지 않는다.

## 반환 형식 이행

이 v1은 다음 개발의 목표다. page.logs는 배열→entries/collection envelope, download.cancel은 boolean→최종 상태 객체, snapshot cursor는 숫자→불투명 문자열로 변경하는 계약을 포함한다. 현재 제품이 이 형식을 제공한다고 가이드하지 않는다. 구현 PR에서 버전/guide/호출 예제·기존 테스트 이행을 한 단위로 수행하고, 다른 형식을 조용히 혼용하지 않는다.
